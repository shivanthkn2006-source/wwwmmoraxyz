## 📝 CONTRIBUTING TO DOCUMENTATION

### Documentation Standards
- Use Markdown format
- Include table of contents for docs >1000 words
- Add code examples where applicable
- Keep language clear and concise
- Update index when adding new docs

### Documentation Workflow
1. Create new document in root directory
2. Follow naming convention: `[CATEGORY]_[FEATURE]_[TYPE].md`
3. Add to this index under appropriate category
4. Update [MASTER_DOCUMENTATION.md](./MASTER_DOCUMENTATION.md)
5. Submit for review
