### What is DHF?

DHF is the continuous learning system that feeds Zoe's intelligence. It captures:

| Data Type | Description | Example |
|-----------|-------------|---------|
| **Voice Commands** | Every voice interaction | "Hey Zoe, schedule meeting" |
| **Behavioral Patterns** | How you use the platform | Morning routines, preferences |

## How Zoe Uses Your Uploaded Intelligence

### 1. Mimicry Mode

When **mimicry** is enabled, Zoe can:

- **Match your writing style** - Emails, messages that sound like you
- **Adopt your tone** - Professional, casual, creative
- **Use your vocabulary** - Industry terms, personal expressions
- **Reflect your personality** - Humor, formality, empathy levels

**Example:**
```
You: "Hey Zoe, write an email to my team about the project delay"
Zoe: [Writes email in YOUR voice, using your typical phrases and style]
```

### 2. Execution Mode

When **execution** is enabled, Zoe can:

- **Perform tasks autonomously** - Based on your skill patterns
- **Make decisions** - Following your documented decision frameworks
- **Create content** - In your creative style
- **Communicate** - In languages you've uploaded

**Example:**
```
You: "Hey Zoe, respond to this client in French"
Zoe: [Uses your uploaded French language pack to respond]
       [Maintains your professional tone and style]
```

### 3. Context Integration

Zoe combines uploaded skills with:

- **DHF behavioral data** - Your patterns and preferences
- **ZSMT memory** - Past conversations and decisions
- **CDSP analysis** - Emotional and need detection
- **Real-time context** - Current situation and goals

```

2. SKILL PROCESSOR: Analyzes, extracts patterns, marks "active"
   ↓
3. USER: "Hey Zoe, respond to this email in French"
   ↓
4. DHF CORE: Logs voice command, captures context
   ↓
5. CDSP: Analyzes user intent, emotional state
   ↓
6. SKILL PROCESSOR: Retrieves French skill with execution enabled
   ↓
7. ZOE CORE: Generates French response using:
   - Uploaded French vocabulary/grammar
   - User's writing style (from DHF patterns)
   - Emotional context (from CDSP)
   ↓
8. OUTPUT: French email that sounds like the user wrote it
```

| **useSkillUpload** | `src/hooks/useSkillUpload.ts` | Skill CRUD, processing, mimicry/execution |

### Database Tables

```sql
-- User Skills Table
user_skills (
  id, user_id, skill_name, skill_type, skill_data,
  file_url, processing_status, mimicry_enabled,
  execution_enabled, capabilities, created_at
)

-- Zoe Sovereign Memory (ZSMT)
zoe_sovereign_memory (
  id, user_id, event_type, event_data,
  context_snapshot, emotional_state, created_at
)

-- Behavioral Events (DHF)
behavioral_events (
  id, user_id, event_type, event_category,
  context_snippet, sentiment_score, dhf_logged
)
```
