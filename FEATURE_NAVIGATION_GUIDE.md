## ⚙️ Settings

**Location:** Profile → Settings Icon

### Lisa AI Settings
**Path:** Settings → Lisa Settings

#### Tabs:
1. **Voice Tab**
   - Wake word configuration
   - Voice pitch, rate, volume
   - Voice gender selection
   - Voice mode (browser/ElevenLabs)
   - Voice feedback toggle
   - Sensitivity settings
   - Output mode (voice/text/both)

2. **Personality Tab** ⭐ NEW
   - Personality tone (casual/professional/enthusiastic/friendly)
   - Conversation style (concise/balanced/detailed)
   - Proactive suggestions toggle
   - Preview examples

3. **Advanced Tab**
   - Voice warmth, grain, breath
   - Emotion controls
   - Speech style
   - Accent settings
   - ElevenLabs parameters
   - Offline mode

4. **Voice Library Tab**
   - Browse voice options
   - Preview voices
   - Select voice style

5. **Language Tab**
   - Select language
   - Auto-detection toggle
   - Preferred language
   - Translation settings

**Voice Commands:**
```
"Open Lisa settings"
"Change personality"
"Show voice options"
```

## 💡 Pro Tips

### Keyboard Shortcuts:
- `Ctrl/Cmd + K`: Quick search
- `Ctrl/Cmd + /`: Show shortcuts
- `Ctrl/Cmd + N`: New post
- `Ctrl/Cmd + M`: Open messages
- `Ctrl/Cmd + L`: Activate Lisa
- `Esc`: Close modal

### Hidden Features:
- **Triple tap** Lisa avatar for debug info
- **Swipe left** on notification for quick actions
- **Long press** post for advanced options
- **Developer mode**: Settings → About → Tap version 7x

### Lisa Power User:
- Create **voice macros** for complex workflows
- Use **personality presets** for different contexts
- Enable **proactive suggestions** for smart reminders
- Check **learning stats** to optimize usage
