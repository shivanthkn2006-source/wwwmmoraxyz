## 💡 TIPS FOR BEST JARVIS-LIKE EXPERIENCE

1. **Clear Speech:** Speak clearly and naturally at normal pace
2. **Wake Word First:** Always say "Hey Zoe" or "OK Zoe" before commands
3. **Wait for Response:** Let Zoe finish speaking before next command
4. **Natural Language:** Commands work with variations (e.g., "show me Mars" = "explore Mars")
5. **Contextual Commands:** When in a feature, you can give direct commands without reopening
6. **Combine Commands:** Once a feature is open, chain commands naturally

### Advanced Command Chaining Example
```
User: "Hey Zoe, open heliosphere"
[Heliosphere opens]

User: "Show me Earth"
[Earth information displays]

User: "Zoom in"
[View zooms closer to Earth]

User: "Now show Jupiter"
[Switches to Jupiter view]

User: "Reset view"
[Returns to default solar system view]
```

## 🔧 TROUBLESHOOTING

**If Zoe doesn't respond:**
- Check microphone permissions
- Ensure wake word detection is enabled in settings
- Speak clearly and wait 1 second after wake word
- Try reloading the page

**If commands don't work:**
- Make sure you're in the correct feature context
- Use tutorial button (?) in each feature for feature-specific commands
- Check that voice notifications are enabled
