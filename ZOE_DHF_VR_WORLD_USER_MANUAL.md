## 🔧 TROUBLESHOOTING

### VR World Won't Load
- WebGL may not be supported
- Try a different browser (Chrome recommended)
- Click "Retry" on error screen

### No Sound
- Check browser permissions
- Click sound toggle to enable
- Interact with page first (browser requirement)

### Timeline Not Responding
- Make sure VR Mode is active
- Timeline only appears in VR

### Mood Not Changing
- Check if "Zoe Automatic Override" is ON
- If ON, Zoe controls the mood
