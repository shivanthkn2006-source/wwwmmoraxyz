# W-870 visual asset

Source: MikeMoon, “Shotgun”, https://opengameart.org/content/shotgun-1
Archive: https://opengameart.org/sites/default/files/Shotgun_2.zip
License: CC0, explicitly verified on source listing on 2026-10-18.
Source describes a Remington 870 modeled in Blender. No Capcom assets used.

Changes: applied source transforms, normalized length to 1.08 m, dark synthetic furniture,
beveled machined edges, metal/roughness separation, packed 128px microfinish textures.
4,247 triangles, 197,536-byte self-contained GLB, two materials. No runtime preload.
Not console-game visual parity; source mesh remains relatively simple.
